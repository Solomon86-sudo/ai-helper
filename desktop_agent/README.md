# Десктопный агент для MS Project

Этот скрипт работает на компьютере планировщика. Он отслеживает сохранения файла `.mpp`, автоматически, через COM-интерфейс Windows, просит MS Project конвертировать график в `.xml` и может отправлять его на бэкенд ERP.

## Установка

1. Убедитесь, что на компьютере установлен **Python 3.9+** и сам **MS Project**.
2. Откройте терминал в этой папке и установите зависимости:
   ```bash
   pip install pywin32 watchdog requests
   ```

## Использование

1. Откройте файл `sync_agent.py` в любом текстовом редакторе.
2. Измените настройки в самом верху файла:
   - `WATCH_DIR` — путь к папке, где планировщик хранит рабочий график.
   - `TARGET_FILE` — точное имя файла (например, `График_СМР.mpp`).
3. Запустите скрипт:
   ```bash
   python sync_agent.py
   ```
4. Теперь планировщик может просто работать в MS Project. При каждом нажатии `Сохранить (Ctrl+S)` скрипт автоматически обновит данные в ERP-системе.
